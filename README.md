# Heads Up — Privacy Policy

Privacy Policy webpage for the **Heads Up** mobile game.

This repository contains the publicly accessible privacy policy used for the Heads Up app distributed through the Google Play Store.

---

## 📱 About Heads Up

**Heads Up** is a fun and fast-paced word-guessing game designed for playing with friends and family.

The app allows users to:

* 🎮 Play word-guessing games
* 🃏 Use built-in word decks
* ✨ Create custom word decks
* 📷 Add images using the camera
* 🖼️ Select images from the device gallery
* 💾 Store custom decks and game-related data locally on the device

The app does not require users to create an account.

---

## 🔒 Privacy

Heads Up is designed with a privacy-first approach.

The app:

* Does not require an account
* Does not collect names, email addresses, phone numbers, or location
* Does not use Firebase
* Does not use advertising services
* Does not use analytics services
* Does not use a backend server to store user data
* Does not upload user-selected or captured images to an external server
* Stores custom decks and game-related information locally on the user's device

Camera and photo access are requested only when the user chooses to add an image to a custom deck.

## 🔄 Updating the Privacy Policy

If the privacy policy needs to be updated:

1. Open `index.html`.
2. Update the required content.
3. Update the **Last Updated** date.
4. Commit the changes.
5. GitHub Pages will automatically publish the updated webpage.

Make sure the policy continues to accurately describe the current data practices and permissions used by the Heads Up app.
